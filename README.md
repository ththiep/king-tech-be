# King Tech Backend

Backend starter for King Tech, built with plain Node.js and no external dependencies.

## Run

```bash
npm start
```

## Development

```bash
npm run dev
```

## Test

```bash
npm test
```

## Endpoints

- `GET /health`
- `GET /api/v1/meta`
- `GET /api/v1/products`
- `POST /api/v1/products`
- `GET /api/v1/products/:id`
- `PATCH /api/v1/products/:id`
- `GET /api/v1/orders`
- `POST /api/v1/orders`
- `GET /api/v1/contacts`
- `POST /api/v1/contacts`

## Environment

Copy `.env.example` to `.env` if you want to customize the port, host, or CORS origin.
